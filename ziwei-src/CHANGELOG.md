# Changelog（交付版）

> 只記功能與修正，依日期倒序。每條盡量寫「改了什麼、為什麼」，讓接手的人知道某段程式為何長這樣。
> 排盤公式狀態見 `FORMULAS.md`，踩過的坑見 `GOTCHAS.md`。

## 2026-09-18 — 流月閏月改依十五分界

- 流月／流日／流時的閏月命宮改為：閏月 1–15 日找當月的流月命宮、16 日起找下月的（日不變），
  與本命安命同一條規則。此前流月對閏月整月不前進 → 閏月 16 日起流月命宮慢一宮，流日／流時連帶偏一宮。
  祿羊陀／四化依節氣月干，本來就不受影響
- 底部 chip 仍獨立列「閏六」；只選閏月未選日＝前半月（`horoscope.ts` `getLunarMonthDay`）

## 2026-09-16 — 進階「數字」cheat sheet

- 進階模式中央卡最下方多一顆「數字」（en `Numbers`）開關，取代原本的 Beta 徽章（ⓘ 說明保留）
- 開啟：每宮疊一張小卡（2×2：`+ 火` / `南 7` ＝ 地支陰陽、五行、方位、河圖數），暫時壓住星曜；
  方位只寫四正（子北／午南／卯東／酉西）；五行字、數字、方位、外框同五行色；`+`／`−` 用陽黑／陰紫
- 開啟時盤面收掉所有運線層回到本命，但底部進階列與已選的流年／月／日／時不動，關掉即刻跳回
- 資料在 `src/lib/branchInfo.ts`（12 支）；盤內暫態，開盤／離盤／關進階即重置

## 2026-09-15 — 紫占（報數起盤）＋ 中央卡直接改名

- 新增視窗右上「🔮 紫占」→「系統隨機」（原隨機起盤）／「輸入數字」：報兩個 1–999 的整數，直接入庫並開盤，
  預設名 `紫占“7，23”`（英文 `Divination (7, 23)`），歸入新預設分類「紫占」
- 亂數法（`src/lib/zizhan.ts`）：可逆的「時辰格」整數 `slot = 天數×13 + timeIndex`，
  `N = 亂數[100-01-01, 9999-12-31] + 數字1 + 數字2` → 生日／時辰／性別。同兩數每次不同盤；
  下限取 100 是避開 JS `new Date(y, …)` 把 0–99 當 19xx 的陷阱
- 命主不在任何大限內（生日在未來、或已超過末限）→ `outOfLife`：預設一限、不高亮、不標紅、不展開童限格，
  開盤維持純本命視圖；童限仍可手動展開
- 編輯視窗年份範圍 1900–2100 → 100–9999
- 分類顯示文字表移到 `storage.ts` 共用，新增視窗的分類按鈕也依語言翻譯
- 正常模式點中央卡名字 → inline 改名（16 字、Enter/失焦存、Esc 取消），與隱藏模式改外號同一套
