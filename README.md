# 癒見幸福 · 魔法占星學院命理排盤工作室 (MeetJoy Divination Atelier)

由愛倫院長親自主持的命理與身心靈排盤專案。本專案完全獨立於預約系統，具備高奢奶油風現代美學與純前端天文星曆演算法。

---

## 系統包含的五大排盤功能

1. **西洋占星本命星盤大典 (`astrology.html`)**
   - NASA JPL / VSOP87 高精度純前端星曆推導
   - 支援全球經緯度與台灣 1945~1979 歷史夏令時間（DST）自動校驗
   - 繪製 360° 雙環圓形星盤（Radix Wheel）、Placidus 普拉西度 12 宮位放射線、四軸（Asc/MC/Dsc/IC）
   - 十大行星、南北交點、逆行判定（℞）與主相位幾何連線網
   - 命主星巴哈花精生活魔藥處方

2. **正統頂規人類圖排盤工作室 (`human-design.html`)**
   - 對標專業水晶立體多面體（3D Faceted Crystal Centers）
   - 64 閘門切面深藍高亮與 36 通道紅黑斑馬條紋雙重啟動
   - 頭頂四顆認知箭頭指示器（The Four Variables）
   - 左右兩側意識黑盤（人格）與設計紅盤（潛意識，太陽倒退 88° 角秒級求解）
   - 點擊中心展開生活魔藥調頻指引

3. **四盤小六壬神數排盤 (`xiao-liu-ren.html`)**
   - 地盤、人盤、神盤、星盤四盤同參
   - 手機極限優化：雙視圖（矩陣大盤 / 逐宮卡片）切換，無排版重疊

4. **文王六爻神卦排盤 (`liu-yao.html`)**
   - 真實三枚銅錢 3D 翻轉互動搖卦與一鍵起卦
   - 京房八宮世應、納甲裝支、定六親、配日干六神、動爻變卦並列對照

5. **基因天命黃金之路 (`gene-keys.html`)**
   - 激活序列、金星序列、珍珠序列
   - 完整 1–64 號「陰影 ➔ 天賦 ➔ 悉地」神聖字典與調頻處方
